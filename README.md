# Zinseszinsrechner

Ein webbasiertes Finanzrechner-Projekt zur Berechnung von Zinseszins, Sparplänen und Kapitalentwicklung über mehrere Jahre.

Funktionen

Berechnung des Endkapitals anhand von:
Startkapital
Monatlicher Sparrate
Zinssatz
Laufzeit
Unterstützung für monatliche und jährliche Zinsausschüttung
Darstellung der Kapitalentwicklung als Diagramm
Anzeige von:
Endkapital
Gesamten Einzahlungen
Erhaltenen Zinserträgen
Integrierter Darkmode

Verwendete Technologien

HTML5
CSS3
JavaScript (ES6)
Chart.js
Decimal.js


Projektziel

Dieses Projekt wurde entwickelt, um meine Kenntnisse in der Webentwicklung und objektorientierten Programmierung mit JavaScript zu vertiefen.

Dabei wurden insbesondere folgende Themen umgesetzt:

Klassen und Objekte
DOM-Manipulation
Event-Handling
Formularverarbeitung
Datenvisualisierung mit Chart.js
Arbeit mit externen Bibliotheken
Benutzerfreundliche Oberflächen

Projekt starten

Variante 1: ZIP-Datei
ZIP-Datei herunterladen.
ZIP-Datei vollständig entpacken.
Den entpackten Ordner öffnen.
Die Datei zinseszinsrechner.html im Browser öffnen.

Variante 2: Git klonen
git clone https://github.com/benya-dev/Zinseszinsrechner

Anschließend den Projektordner öffnen und die Datei zinseszinsrechner.html im Browser starten.
